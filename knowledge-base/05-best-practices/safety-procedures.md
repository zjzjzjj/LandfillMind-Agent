## 0. Agent 使用说明（必读）

| 场景 | 回答策略 |
|------|---------|
| 用户问"能不能下去/进池子/进导气井" | **一律先答"有限空间作业，必须先审批+检测+通风+监护"**，再给流程（见 §1.3） |
| 用户报某气体浓度 | 用 §1.2 判据表直接判"合格/超标/立即撤离"，给出数值边界 |
| 用户问监测频率 | 用 §3 表格，区分**运行期 / 封场后** |
| 用户描述异常（位移加速、液位上升、冒烟、恶臭） | 用 §4 分级响应，**先人员撤离，后处置** |
| 涉及生命危险 | 输出必须以**停止作业 / 撤离 / 拨打 119、120** 开头，不得先讲技术分析 |
| 数据不确定 | 明确说"以现场排污许可证及本场应急预案为准"，不臆造限值 |

**红线口径（任何情况下不得妥协）**：
1. 未办票、未检测、无监护 → 严禁进入有限空间。
2. 发现人员在有限空间内昏迷 → **严禁无防护施救**（80% 以上事故死亡为盲目施救所致）。
3. 甲烷 ≥ 1.25%（体积）报警 → 立即断电、禁火、撤离。
4. 边坡位移速率连续 2 天 > 10 mm/d → 启动应急，停止堆填。

## 1. 作业人员安全（Worker Safety）

### 1.1 个人防护装备 PPE

| 作业类型 | 必配 PPE |
|---------|---------|
| 一般填埋作业区巡查 | 安全帽、反光背心、防砸防刺穿劳保鞋、手套、口罩 |
| 作业面/推铺压实 | 上述 + 便携式四合一气体检测仪（O₂/CH₄(LEL)/H₂S/CO）、防噪耳塞 |
| 渗滤液区域 | 上述 + 防化服/防水围裙、护目镜、耐酸碱手套 |
| 有限空间进入 | **正压式空气呼吸器 SCBA 或长管供气呼吸器**（严禁用过滤式面具）、全身式安全带 + 三脚架绞盘、防坠器、安全绳、防爆照明与对讲、连续监测仪 |
| 动火作业 | 阻燃工作服、焊接面罩、灭火器材、防火毯 |
| 高处/边坡作业 | 双钩安全带、生命线 |

要点：
- 过滤式（防毒面具）在 **缺氧（O₂<19.5%）或 IDLH 环境完全无效**，填埋场深井/调节池默认按缺氧处理。
- 气体检测仪须**每日开机自检、每年强检**（JJG 695 H₂S、JJG 915 CO 校准规范）。
- 现场至少**备两套以上隔绝式呼吸器**供应急救援用。

### 1.2 气体接触限值与现场判据（核心速查表）

| 气体 | 职业接触限值（GBZ 2.1-2019） | 现场作业判据 | 危险值 |
|------|------|------|------|
| 硫化氢 H₂S | **MAC 10 mg/m³**（≈6.6 ppm，最高容许浓度，任何时刻不得超） | 进入前 <10 mg/m³；>10 mg/m³ 须佩戴隔绝式呼吸器 | 100 ppm 嗅觉麻痹（"闻不到更危险"）；≥700 ppm 数秒内昏迷致死 |
| 甲烷 CH₄ | 单纯窒息性气体，按 LEL 控制 | **爆炸下限 LEL=5%**；报警设定 **1.25%（25% LEL）**；作业允许值 ≤0.5%（体积） | 5%~15% 遇火即爆；高浓度置换氧气致窒息 |
| 氧气 O₂ | — | **合格区间 19.5%~23.5%**（GB 30871 严格口径 19.5%~21%，富氧不得 >23.5%） | <19.5% 缺氧；<16% 判断力下降；<10% 数分钟昏迷死亡；>23.5% 富氧燃爆风险 |
| 一氧化碳 CO | PC-TWA 20 mg/m³，PC-STEL 30 mg/m³ | <20 mg/m³（≈17 ppm） | ≥1700 mg/m³ 立即危及生命 |
| 氨 NH₃ | PC-TWA 20 mg/m³，STEL 30 mg/m³ | 恶臭伴随指标 | 刺激性预警 |
| CO₂ | PC-TWA 9000 mg/m³ | 沉积于低处，与缺氧并发 | >5% 明显中毒 |

**判据口诀（Agent 直接引用）**：
> 氧 19.5–23.5，甲烷 <0.5%（报警 1.25%），硫化氢 <10 mg/m³，一氧化碳 <20 mg/m³ —— **四项全合格才可进入，任一超标立即撤离并强制通风**。

### 1.3 有限空间作业（Confined Space Entry）标准流程

填埋场典型有限空间：渗滤液调节池/收集井、垂直导气井、泵坑、检查井、格栅间、地下管廊、封闭式垃圾坑、沼气储罐。

**"先通风、再检测、后作业"——严禁通风、检测不合格作业。**

| 步骤 | 要求 |
|------|------|
| 1. 辨识与审批 | 填《有限空间作业审批票》，明确作业内容、危害辨识、措施、监护人；单位负责人签批 |
| 2. 隔离置换 | 关闭并挂牌上锁（LOTO）相关阀门/电源；加盲板隔断；必要时氮气/清水置换 |
| 3. 强制通风 | 机械通风 ≥15 min，风量保证换气 ≥3 次/h；**严禁向内充纯氧** |
| 4. 作业前检测 | 作业开始前 **30 min 内**取样；对上、中、下（左中右）**分层多点检测**；记录留存 |
| 5. 监护 | 至少 1 名专职监护人**全程在外**，不得离岗、不得兼作业；保持不间断呼应或对讲 |
| 6. 连续监测 | 作业期间连续或至少每 30 min 检测一次；作业中断 >30 min 须重新检测方可再入 |
| 7. 防护与救援 | 佩戴安全带+安全绳，绳端固定于外部三脚架；救援装备现场待命 |
| 8. 收尾 | 清点人员工具，恢复隔离设施，闭票归档 |

**票证有效期**：一般一次作业一票，作业条件变化（人员、内容、环境）须重新办票。

### 1.4 动火作业（Hot Work）

填埋场是**天然甲烷环境**，动火风险极高（焊接导气管、检修设备、切割）。

| 项目 | 要求（参照 GB 30871-2022） |
|------|------|
| 分级 | 特级 / 一级 / 二级动火；填埋堆体上方、导气/沼气系统周边应按**一级及以上**管理 |
| 有效期 | 特级、一级 **≤8 h**；二级 **≤72 h** |
| 检测 | 动火前分析取样与动火开始间隔 **≤30 min**；可燃气体 **<0.5%（LEL≥4% 时）或 <0.2%（LEL<4% 时）** |
| 升级管理 | 节假日、夜间动火升级审批 |
| 现场条件 | 清除 10 m 内可燃物；配灭火器/水带/接火盘；设专职看火人；特级动火**连续监测 + 防爆摄录全程录像**（保存 ≥1 个月） |
| 完工 | 动火结束后现场观察 **≥30 min** 确认无阴燃 |
| 禁止 | 雨天露天电焊、堆体裂缝冒气处动火、无票动火 |

### 1.5 其他常态安全

- **车辆与机械**：作业面单向行车、倒车有人指挥、压实机上下坡沿最大坡度方向行驶（禁横向行驶）、夜间照度 ≥50 lx。
- **防火**：堆体禁火禁烟，设隔离带与消防水源；覆盖不到位是深层阴燃火灾主因。
- **职业健康**：接触 H₂S/恶臭/噪声岗位建立职业健康监护档案，上岗前、在岗期间、离岗时体检。
- **培训**：有限空间、动火、应急救援作业人员**持证上岗**，每年至少 1 次实操演练。

## 2. 日常填埋作业（Daily Operations）

### 2.1 单元作业法（Cell Method）

标准流程：**卸料 → 推平 → 分层压实 → 日覆盖 → 边坡整形**

| 参数 | 标准值 | 说明 |
|------|--------|------|
| 作业单元宽度 | 一般 6~15 m（按日进场量与车辆数确定） | 缩小暴露面，控制蝇臭 |
| 摊铺分层厚度 | **每层 ≤60 cm**（碾压前松铺） | 过厚压不实 |
| 碾压遍数 | 同一位置 **3~5 遍**（压实机 3~5 次往复） | |
| **压实密度** | ≥**600 kg/m³**（GB 50869 要求；良好管理可达 800~1000 kg/m³） | 直接决定库容与稳定性 |
| **作业坡比** | 不陡于 **1:3**（垂直:水平），临时作业面可 1:2 但须及时整形 | 坡比过陡是滑坡首因 |
| 单元层高 | 每层填埋高度宜 2~4 m，不宜 >6 m | |
| 台阶（平台） | 每升高 10~15 m 设一级马道，宽 ≥3~5 m | 兼作检修道与排水 |

### 2.2 覆盖要求

| 类型 | 厚度 | 材料 | 时机/条件 |
|------|------|------|-----------|
| **日覆盖** | **15~30 cm** 土；或 HDPE/LLDPE 膜（厚度 ≥0.1 mm）等临时覆盖材料 | 黏土、土工膜、喷洒型覆盖剂 | **每日作业结束后立即完成**，不得过夜裸露 |
| **中间覆盖** | **≥30 cm**（土；一般 30~50 cm），或膜 + 土组合 | 黏土渗透系数宜 ≤1×10⁻⁵ cm/s | 单元停止作业 **超过 1 个月**（或规范/预案规定期限）、雨季来临前、临时通行面 |
| **封场终场覆盖** | 见 §5 多层结构 | | 填埋达到设计标高后 |

覆盖的三大功能：控臭与蝇鼠、**阻雨水入渗（减渗滤液产量）**、防火与防气体无组织逸散。

### 2.3 雨污分流与作业面管理（关键降本项）

- 场区**截洪沟**须完好，防止外部径流进入填埋区。
- 作业区与已覆盖区之间设**临时导流土埂**，实现"清污分流"。
- 未填埋区雨水单独收集外排（GB 16889 要求雨水排口每月监测 COD/氨氮/SS）。
- 暴雨前：完成中间覆盖、检查排水沟、下调渗滤液调节池液位预留调蓄容量。

## 3. 监测频次（Monitoring Frequency）—— 速查表

### 3.1 堆体稳定与渗滤液水位（GB 50869 / 稳定性监测惯例）

| 监测项 | 正常期 | 雨季/汛期 | 预警状态 |
|--------|--------|-----------|----------|
| 堆体表面水平位移、沉降 | 1 次/月（三级场可 1 次/30 d） | 1 次/周 | **1 次/日或连续自动监测** |
| 深层水平位移（测斜） | 1 次/季 | 1 次/月 | 加密 |
| **渗滤液导排层水头 / 堆体主水位** | 1 次/月（重点场 1 次/周） | 1 次/周 | 每日 |
| 滞水位（次生水位） | 1 次/月 | 加密 | 每日 |

**预警阈值（工程通用）**：
- 表面水平位移速率 **>10 mm/d 且连续 2 天** → 报警；
- 位移由毫米级/天跃升至**厘米级/天** → 临滑，立即撤离；
- **渗滤液水位 h / 堆体高度 H > 0.7** → 稳定安全系数显著下降；水位超过堆体一半后，每再升 10%，稳定系数约降 25%；
- 导排层水头设计控制：**渗滤液导排层上水头 ≤30 cm（0.3 m）**，堆体内不得形成高水位。
- 稳定安全系数 Fs：运行工况一般要求 **≥1.25~1.35**，地震/极端工况 ≥1.05~1.1（以设计文件为准）。

**水位管布设**：竖向水位管沿边坡走向分散布置，**平面间距 20~40 m**，管底距衬垫层 **≥5 m**，总数 ≥2 个；水平水位管在每个排水单元的收集主管附近和最远端各 1 个。

### 3.2 环境监测（GB 16889-2024）

| 对象 | 运行期频次 | 封场后频次 |
|------|-----------|-----------|
| 地下水 — 导排管出口污染监测井 | **≥1 次/周** | ≥1 次/季度 |
| 地下水 — 污染扩散井、污染监视井 | **≥1 次/2 周** | ≥1 次/季度 |
| 地下水 — 本底井（上游） | **≥1 次/月** | ≥1 次/季度 |
| **甲烷（填埋场上方及建构筑物内）** | **≥1 次/日** | 按预案，建议 ≥1 次/日或在线报警 |
| 渗滤液排放口 | 在线监测 + 手工 ≥1 次/月 | 按许可证 |
| 雨水排放口（COD、氨氮、SS 等） | ≥1 次/月 | — |
| 场界恶臭污染物 | ≥1 次/月 | 按预案 |
| 无组织废气 | ≥1 次/季度 | — |
| 土壤 | ≥1 次/年 | 按预案 |
| 地表水 | ≥1 次/月（按许可证） | 按预案 |
| **防渗衬层完整性检测** | **≥1 次/6 个月** | **≥1 次/3 年** |

**地下水井布设**：上游本底井 1 眼；下游污染监视井 ≥2 眼；两侧污染扩散井各 ≥1 眼；地下水导排系统出口 1 眼。
**地下水监测指标**：pH、总硬度、溶解性总固体、耗氧量、氨氮、硝酸盐、亚硝酸盐、硫酸盐、氯化物、挥发性酚类、氰化物、砷、汞、总铬、六价铬、铅、氟化物、镉、铁、锰、铜、锌、镍、铍、总大肠菌群等 25 项。
**异常处置**：监测结果异常应在 **3 日内复测**，并视情增加监测项目、启动溯源与衬层破损检测。

**场界/建构筑物甲烷控制**：建（构）筑物内甲烷报警浓度设定 **1.25%（体积分数）** = 爆炸下限 5% 的 25%；填埋场覆盖层上方甲烷体积分数应 <5%（老版 GB 16889-2008 口径，仍作为工程控制通用参考，具体限值以现行标准与排污许可证为准）。

## 4. 应急响应（Emergency Response）

### 4.1 通用原则
1. **保人第一**：先撤人、划警戒、后处置。
2. **上风向撤离**，集合点设在上风、高处、场外。
3. 分级响应 Ⅰ~Ⅳ 级；超出自身能力立即上报并报警（119 / 120 / 生态环境部门）。
4. 每年至少组织 **1 次综合演练 + 2 次专项演练**（滑坡、渗滤液外溢、中毒窒息、火灾）。

### 4.2 堆体滑坡 / 边坡失稳

**征兆**：坡面/坡顶出现**弧形拉裂缝**、坡脚鼓胀隆起、渗滤液从坡面渗出（"流土"）、位移速率突增、覆盖层错台。

处置：
1. **立即停止该区域一切填埋、行车、施工作业**，人员与机械撤至滑动区外（不小于坡高 1.5 倍水平距离），设警戒线。
2. 卸载减载：**坡顶减载**（清除上部垃圾/土方），**坡脚反压**（堆填压重土袋、渣土）。
3. **降水位是根本**：开启/增设深层竖井抽排、水平导排盲沟自流导出，快速降低堆体内渗滤液水位。
4. 坡面截排水：坡顶截水沟导排、裂缝用黏土/膜临时封填，防雨水灌入裂缝加速滑动。
5. 加密监测：改为**连续/每日**位移与水位观测，设置观测标志与人工巡视。
6. 评估：请专业单位复核稳定性（极限平衡/有限元），出具处置方案后方可复工。
7. 若威胁场外居民/水体 → 上报政府启动区域疏散。

### 4.3 渗滤液外溢 / 调节池溢流 / 管道泄漏

1. **切断源头**：停止向该池/管输送，关闭相关阀门；启用备用池与应急调蓄。
2. **围堵拦截**：在下游布设土袋/沙袋围堰、临时土坝，防止进入雨水沟、河道；必要时封堵雨水排口。
3. **收集回抽**：吸污车/移动泵抽回调节池；渗滤液外运协调（提前与有资质单位签订应急协议）。
4. **处理提负荷**：提高渗滤液处理站运行负荷，必要时投加应急药剂。
5. **修补点位**：外泄点位（堆体边坡、池壁、管道）用黏土/HDPE 膜/管卡临时修补，后期永久修复。
6. **环境跟踪**：立即对下游地表水、地下水加密采样（COD、氨氮、重金属），跟踪至恢复本底。
7. **报告**：可能造成水体污染的，属突发环境事件，须**1 小时内**向属地生态环境部门报告。
8. 预防：调节池设**液位在线监测与高液位报警**，汛期保持预留调蓄容积（一般 ≥20% 有效容积）。

### 4.4 填埋气泄漏 / 甲烷超标 / 火灾爆炸

| 情形 | 处置 |
|------|------|
| 建构筑物内甲烷报警（≥1.25%） | 立即停止作业 → 禁火禁打手机/开关电器 → 开门窗强制通风 → 人员撤离至上风安全区 → 检漏与堵漏 → 复测合格后方可进入 |
| 导气井/管道泄漏 | 关闭对应阀门，隔离区域，警戒半径按浓度确定（初期 ≥25~50 m），持续检测 |
| 堆体表面阴燃/冒烟 | **禁止大量注水**（易致塌陷与蒸汽伤人）；采用**开挖隔离带 + 惰性土覆盖窒息法**，配合黄土/泥浆灌注；持续测温 |
| 明火火灾 | "救人重于救火，先控制后消灭"；切断电源，干粉/泡沫灭火；拨打 119；防止蔓延至气体收集系统 |
| 爆炸风险区 | 一切设备使用**防爆型**；禁止使用非防爆手电、手机、相机 |

### 4.5 中毒窒息与人员救援（最高优先级）

**发现有人在有限空间内昏倒：**
1. **严禁徒手下井施救**！立即呼叫并启动应急，通知现场负责人。
2. 拨打 **120 / 119**（消防具备专业救援能力）。
3. 外部救援优先：利用**三脚架 + 绞盘 + 安全绳**从外部提升（作业前已系好安全带的前提下）。
4. 必须进入时：救援人员佩戴 **正压式空气呼吸器**、系安全绳、由第二名监护人在外接应，**至少 2 人以上防护到位**。
5. 同时开启**强制通风**，持续气体检测。
6. 伤员救出后移至上风新鲜空气处，松解衣物，无呼吸者立即 **CPR**（H₂S 中毒禁止口对口人工呼吸，改用简易呼吸器/球囊）；有条件给氧。
7. 保护现场，配合事故调查；4 h 内按规定上报事故。

**警戒与疏散参考**：危险区边界设黄黑警戒带，边界 **50 m** 内无关人员撤离；重大泄漏时场界周边 **50~100 m** 范围人员按指定路线有序疏散。

### 4.6 应急物资清单（现场常备）

正压式空气呼吸器（≥2 套）、便携四合一气体检测仪（≥2 台）、三脚架与绞盘、安全绳与全身安全带、防爆轴流风机与风管、防爆照明与对讲机、担架与急救箱与氧气袋、吸污车/移动泵、沙袋土袋、HDPE 膜与黏土、灭火器与消防水带、警戒带与标识牌、应急照明发电机。

## 5. 封场标准（Closure）——GB 51220-2017

### 5.1 终场覆盖系统（自下而上，标准断面）

| 层次 | 材料与厚度 | 功能 |
|------|-----------|------|
| ① 排气层 | 碎石等颗粒材料，**厚度 ≥300 mm**，粒径 **20~40 mm**，CaCO₃ 含量 ≤10%；或土工网状导排材料厚度 ≥5 mm；配 ≥300 g/m² 土工滤网 | 导排填埋气至竖向导气井 |
| ② 防渗层 | HDPE 土工膜 **≥1.0 mm**（宜糙面）+ GCL 膨润土垫，或压实黏土层 ≥300 mm（k ≤1×10⁻⁷ cm/s） | 阻断雨水入渗、控制气体逸散 |
| ③ 排水层 | 碎石 ≥300 mm 或土工复合排水网 | 排除渗入雨水，降低膜上水头 |
| ④ 绿化土层（植被层） | 营养土 + 覆盖支持土，总厚 **≥500 mm**（其中营养土 ≥150 mm，宜 300 mm） | 植被生长、抗侵蚀 |

**封场坡度**：顶面坡度宜 **≥5%**（保证排水，避免积水）；边坡坡度不宜陡于 **1:3**，每 10~15 m 高差设一级 **≥3 m** 宽平台，平台设排水沟。

### 5.2 配套工程
- 填埋气导排：竖向导气井 + 集气管网，具备条件时火炬燃烧或发电利用；甲烷监测报警设施（报警值 **1.25%**）。
- 渗滤液：收集导排与处理系统继续运行，直至水质稳定达标。
- 地表水：截洪沟、排水沟、沉砂池维持完好。
- 沉降监测点：堆体表面按网格布设，长期观测。

### 5.3 封场后维护与监测期
- **后期维护与监测期不少于 30 年**（GB 16889-2024 及配套要求；地方可要求更长，直至堆体稳定化并通过评估）。
- 期间持续：地下水/地表水/渗滤液/填埋气/恶臭/沉降监测；**每 3 年 1 次防渗衬层完整性检测**；结合地下水水质定期开展**环境风险评估**。
- 维护内容：覆盖层裂缝与沉降坑修补、植被补种、排水与导气系统清淤检修、围栏标识维护。
- 建立长期档案（监测报告、修复记录），责任可追溯。
- **场地再利用**：未经稳定化评价与主管部门批准，不得用于建筑建设；一般先用于绿地、公园、光伏等低敏感用途。

### 5.4 植被要求
- 优先浅根、耐旱、耐贫瘠的**草本与灌木**；**严禁种植深根乔木**（根系刺穿防渗膜）。
- 顶面以草坪/地被为主；边坡采用固土植被 + 生态毯防冲刷。
- 覆绿率宜 ≥90%，成活后 2 年内加强养护与补种。

## 6. 合规、报告与台账（Compliance）

### 6.1 排污许可证
- 生活垃圾填埋场属**排污许可重点管理**行业（环境卫生管理业，参照 HJ 1106 技术规范申领）。
- 许可证载明：许可排放口、污染物种类与限值、自行监测方案、台账记录要求、执行报告频次。
- **执行报告**：重点管理单位提交**年度执行报告 + 季度执行报告**（部分要求月报）；内容含污染物排放浓度/总量、超标情况与原因、治理设施运行、自行监测执行情况。
- **台账记录**：一般不少于 **5 年**保存期；含进场量、覆盖记录、渗滤液处理量与水质、填埋气处置、异常与应急记录。
- 变更（工艺、规模、排放口）须及时办理**变更/重新申请**。

### 6.2 自行监测
- 依据 **HJ 819《排污单位自行监测技术指南 总则》** 及行业指南编制《自行监测方案》，向社会公开。
- 监测结果通过**全国排污许可证管理信息平台 / 企业事业单位环境信息依法披露系统**公开。
- 在线监测设备（渗滤液排口 COD、氨氮、流量）须联网、定期比对校验，数据传输有效率达标。
- 频次不得低于 §3.2 表格与许可证要求；就高不就低。

### 6.3 安全生产合规
- 有限空间**作业场所辨识清单 + 明显警示标志**，报属地应急管理部门备案。
- 建立并演练**生产安全事故应急预案**（综合 + 专项 + 现场处置方案），依法备案。
- 特种作业人员持证（焊工、电工、起重、有限空间救援等）。
- 双重预防机制：风险分级管控 + 隐患排查治理，留痕可查。
- 事故报告：一般事故 1 h 内报告属地应急管理与行业主管部门，不得瞒报迟报。

### 6.4 突发环境事件
- 编制**突发环境事件应急预案**并向生态环境部门**备案**（一般 3 年修订一次）。
- 定期开展环境风险评估、环境应急资源调查。
- 事件发生后 **1 小时内**报告，并按 Ⅰ~Ⅳ 级响应处置、信息公开。
