## 1. 边坡稳定 Fs 计算

**参考标准：** CJJ 176-2012 第6章；GB 50485-2009；CJJ 113-2007

### 1.1 瑞典圆弧法 (Fellenius)

```
Fs = Σ{[c'·Lᵢ + (Wᵢ·cos αᵢ − uᵢ·Lᵢ)·tan φ']} / Σ{Wᵢ·sin αᵢ}
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| Fs | 抗滑稳定安全系数 | - | >1 安全，=1 临界，<1 失稳 |
| c' | 有效黏聚力 | kPa | 垃圾 5~30；黏土 10~50；HDPE 界面 0~5 |
| Lᵢ | 第i条块滑弧长度 | m | - |
| Wᵢ | 第i条块重量 | kN/m | Wᵢ = bᵢ·hᵢ·γᵢ |
| αᵢ | 第i条块底面倾角 | ° | 滑出段为正 |
| uᵢ | 条块底面孔隙水压力 | kPa | 渗滤液水位作用下产生 |
| φ' | 有效内摩擦角 | ° | 垃圾 20~35；HDPE/织物界面 8~18 |

**适用条件：** 圆弧滑动面；层状堆体（多层垃圾/土工膜/黏土）；初算/手算
**优点：** 简单、结果偏保守（低估5~20%）
**限制：** 忽略条间力；只满足力矩平衡；非圆弧面需用 Janbu/Spencer
**来源：** Fellenius 1927 / CJJ 176-2012 §6.5

---

### 1.2 Bishop 简化法

```
Fs = Σ{[c'·bᵢ + (Wᵢ − uᵢ·bᵢ)·tan φ']/mα} / Σ{Wᵢ·sin αᵢ}

mα = cos αᵢ + (sin αᵢ·tan φ') / Fs   ← 迭代求解
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| bᵢ | 条块宽度 | m | 0.5~2 |
| mα | Bishop 几何系数 | - | 含 Fs 迭代 |
| R | 滑弧半径 | m | - |

**适用条件：** 圆弧滑动；考虑条间水平力（忽略切向）
**迭代步骤：**
1. 初设 mα⁽⁰⁾ = cos αᵢ
2. 代入求 Fs⁽¹⁾
3. 用 Fs⁽¹⁾ 重算 mα⁽¹⁾
4. 迭代至 |Fs⁽ⁿ⁺¹⁾ − Fs⁽ⁿ⁾| < 1×10⁻³

**优点：** 比瑞典圆弧精度高，与严格方法误差 <5%
**限制：** 仅适用圆弧；非圆弧（沿土工膜界面）需用 Janbu/Spencer
**来源：** Bishop 1955 / CJJ 176-2012 §6.5

---

### 1.3 Janbu 法

```
Fs = f₀ · Σ{[c'·bᵢ + (Wᵢ − u·bᵢ)·tan φ']/mα_J} / Σ{Wᵢ·tan αᵢ}

mα_J = cos²αᵢ · (1 + tan αᵢ·tan φ'/Fs)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| f₀ | Janbu 经验修正系数 | - | 1.0~1.4（查表） |
| Wᵢ | 第i条块重量 | kN/m | - |
| αᵢ | 条块底面倾角 | ° | - |

**适用条件：** **任意形状滑动面**（折线、复合、沿土工膜界面）；HDPE 衬垫界面滑动分析首选
**优点：** 可分析非圆弧滑动；条文间力假设
**限制：** 精度依赖 f₀；满足水平力平衡但不严格满足力矩平衡
**典型界面参数：** 土工膜/土工织物界面：c'≈0, φ'≈8~15°
**来源：** Janbu 1954/1973 / CJJ 176-2012 §6.5

---

### 1.4 拟静力抗震 Fs

```
Fs = Σ{[c'·Lᵢ + (Wᵢ·cos αᵢ − uᵢ·Lᵢ)·tan φ']} / Σ{Wᵢ·sin αᵢ + kh·Wᵢ·(hᵢ/R) + kv·Wᵢ·sin αᵢ}
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| kh | 水平向地震系数 | - | 0.5·PGA/g ≈ 0.05~0.20 |
| kv | 垂直向地震系数 | - | 0.5·kh（近断层）至0（远场） |
| PGA | 峰值地面加速度 | g | 7度0.10g，8度0.20g，9度0.40g |
| hᵢ | 条块中心至滑动圆心竖距 | m | 用于计算惯性力矩 |
| R | 滑弧半径 | m | - |

**简化 kh 估算：** kh = 0.5 × PGA/g （Matasovic & Kavazanjian 1998 推荐）
**适用：** CJJ 176-2012 非常运用条件Ⅱ（地震工况）
**进阶：** Newmark 位移法 d = f((1−Fs)/kh, 地震时程)；允许永久位移 5~15 cm
**来源：** CJJ 176-2012 §6.1.3 / Seed 1979 / Mononobe-Okabe

---

### 1.5 安全系数阈值

**CJJ 176-2012 表 6.1.4**

| 安全等级 | 边坡高度 | 正常工况 | 非常Ⅰ（暴雨） | 非常Ⅱ（地震） |
|---------|---------|---------|--------------|--------------|
| 一级 | H ≥ 60 m | **1.35** | 1.30 | 1.15 |
| 二级 | 30 ≤ H < 60 m | **1.30** | 1.25 | 1.10 |
| 三级 | H < 30 m | **1.25** | 1.20 | 1.05 |

**升级条件：** 对下游有重要设施/软基/山谷型（坡度>10°），安全等级提升一级，安全系数相应提高 10%。

## 2. 渗滤液产量 HELP 模型

**参考：** US EPA HELP v3.07 (1994) / CJJ 176-2012 第7章

### 2.1 经验公式 Q = C·A·I

```
Q = C · A · I · 10⁻³   (m³/d)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| Q | 渗滤液日产量 | m³/d | 1000~10000（中型填埋场） |
| C | 产污系数/径流系数 | - | 0.20~0.50 |
| A | 填埋场汇水面积 | m² | 10万~50万 |
| I | 多年平均日降雨量 | mm/d | 南方2~5；北方0.5~2 |

**优点：** 简单，初步估算
**限制：** 忽略蒸发、储水，误差30~50%
**来源：** HJ 564-2010

---

### 2.2 水量平衡法

```
P = R + ET + ΔS + L + SRO + INT   (mm/d)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| P | 降水量 | mm/d | 全年输入 |
| R | 地表径流 | mm/d | 10~30% P |
| ET | 蒸散发量 | mm/d | 干旱季节主导输出 |
| ΔS | 土壤含水层储水变化 | mm/d | 长期累计趋于0 |
| L | 渗滤液下渗量 | mm/d | 30~60% P |
| SRO | 地表径流（含初始雨） | mm/d | 取决于坡度与覆盖 |
| INT | 植被截留 | mm/d | <2 mm/雨次 |

**渗滤液量换算：**
```
Q (m³/d) = L (mm/d) × A (m²) × 10⁻³
```

**月修正系数：** 0.6~1.4（雨季>1）
**来源：** US EPA HELP v3.07 / CJJ 176-2012 §7.2

---

### 2.3 HELP 模型分层结构

**自上而下分层：**

| 序 | 层名 | 作用 |
|---|------|------|
| 1 | 植被/覆盖层 | 截留、减少ET |
| 2 | 顶部土层（封场覆盖） | 蓄水、蒸发带 |
| 3 | 排水层（砂/砾+土工网） | 侧向排出渗滤液 |
| 4 | 土工膜（HDPE 防渗） | 阻止下渗 |
| 5 | GCL / 压实黏土 CCL | 吸附缓冲层 |
| 6 | 原状地基土 | 最终屏障 |
| 7 | 地下水层（毛管水带） | 潜水面 |

**关键渗流量：** q_perc = k_sat · i（Darcy 定律）；通过每层水量受其 k 值控制（最低层决定渗率）
**来源：** HELP Model v3.07 User Guide (1994)

## 3. 填埋气产量 LandGEM 模型

**参考：** US EPA LandGEM v3.02 (2005) / IPCC 2006 Guidelines Vol.5 Ch.3

### 3.1 一阶衰减产气公式

```
Q_CH4 = Σᵢ₌₁ⁿ Σⱼ₌₀.₁¹ k · L₀ · (Mᵢ/10) · exp(−k · tᵢⱼ)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| Q_CH4 | 甲烷年产气量 | m³/yr | 10⁵~10⁷ |
| k | 甲烷产气速率常数 | 1/yr | 0.04~0.05（EPA默认）；0.2~0.4（湿填埋场）；0.01~0.05（干旱） |
| L₀ | 甲烷产气潜能 | m³/Mg | 100（亚洲默认）/ 170（美国法规）；范围 56.6~312 |
| Mᵢ | 第i年填埋垃圾质量 | Mg | 干基或湿基，注意转换 |
| tᵢⱼ | 第i年垃圾第j时段龄期 | yr | tᵢⱼ = (接收年至计算年 − i + (1−j)) |

**碳比例假定：** CH₄:CO₂ ≈ 50:50
**总产气量：** Q_total = Q_CH4 / 0.5

---

### 3.2 IPCC 经验 k 公式

```
k = 3.2×10⁻⁵ · MAP + 0.01   (1/yr)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| MAP | 多年平均降雨量 | mm/yr | 深圳 1700 → k ≈ 0.064；北京 540 → k ≈ 0.027 |

**适用：** 数据缺乏时估算 k
**来源：** IPCC 2006 Guidelines Vol.5 Ch.3

---

### 3.3 IPCC 经验 L₀ 公式

```
L₀ = MCF × DOC × DOCf × F × 1.334   (m³/Mg)
```

其中 1.334 = 16/12（CH₄/C 摩尔质量比）

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| MCF | 甲烷修正因子 | - | 管理填埋场 1.0；未管理 0.5~0.8 |
| DOC | 可降解有机碳比例 | kg C/kg waste | 0.15~0.20（生活垃圾） |
| DOCf | DOC 分解比例 | - | 0.50~0.77（管理填埋场取 0.5） |
| F | 垃圾中甲烷比例 | - | 0.5 |
| 16/12 | CH₄/C 摩尔质量比 | - | 1.334（常数） |

**来源：** IPCC 2006 Guidelines Vol.5 Ch.3 Eq.3.4

## 4. 沉降预测 双曲线法

**参考：** CJJ 176-2012 §5.2 / 公路路基规范 JTG D30

### 4.1 双曲线法基本公式

```
S(t) = S₀ + (t − t₀) / [a + b·(t − t₀)]
```

**线性化形式（用于最小二乘拟合）：**
```
(t − t₀) / (S − S₀) = a + b·(t − t₀)
```

**最终沉降（t→∞）：**
```
S∞ = S₀ + 1/b
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| S(t) | t 时刻的沉降量 | cm | 取决于垃圾厚度 |
| S₀ | 参考时刻 t₀ 的初始沉降 | cm | 通常取填埋后 3~6 个月 |
| t | 自参考时刻起算的时间 | d | 用 30~180 d 以上数据回归 |
| a | 回归系数（斜率倒数） | d/cm | 由实测数据回归 |
| b | 回归系数（衰减） | 1/cm | b = 回归斜率 |

**典型参数：** 垃圾堆体：a=0.05~0.20, b=0.001~0.005 (1/cm)；S∞ = 200~600 cm
**数据要求：** ≥ 90~180 d 沉降实测数据；越接近稳定，b 越准确
**限制：** 经验公式；理论上不收敛；前期沉降大时预测偏大
**来源：** CJJ 176-2012 §5.2 / JTG D30-2015 附录

---

### 4.2 次压缩沉降（蠕变）

```
Sₛ = Cα · H₀ · log(t / t₁)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| Cα | 次压缩系数 | - | 垃圾 0.05~0.30 |
| H₀ | 垃圾层初始厚度 | m | 对应填埋时的厚度 |
| t | 当前时间 | d | - |
| t₁ | 主压缩结束时间 | d | 30~180 d |

**来源：** Mesri 1985 / CJJ 176-2012 §5.2.4

## 5. HDPE 土工膜验算

**参考：** CJJ 176-2012 §6.6 / CJJ 113-2007 附录D / GRI GM13/GM19 / CJ/T 234-2006

### 5.1 土工膜拉应变验算

**Giroud 1995 简化近似：**
```
εₘ ≈ 2·f·π / (L + 2·f)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| εₘ | 土工膜最大拉应变 | % | 允许 ≤ 5~8%；HDPE 屈服 12~15% |
| δ | 凹陷深度 | m | 局部下沉产生的凹陷变形 |
| L | 凹陷跨度 | m | 沉降差异两端的距离 |
| f | 凹陷最大挠度 | m | - |

**判定：** 若 εₘ > 允许应变 → 增加加筋（GCL 或土工格栅）
**来源：** Giroud 1995 / CJJ 176-2012 附录B

---

### 5.2 焊缝强度验算

```
σ_weld ≥ σ_base × k_seam
f_weld ≥ f_base × k_seam
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| f_weld | 焊缝抗剪/剥离强度 | N/mm | HDPE 1.5mm 热楔焊：剪切 ≥21.2，剥离 ≥15.7 |
| f_base | 母材抗拉/抗剪强度 | N/mm | HDPE 屈服 22~27 MPa |
| k_seam | 焊缝强度折减系数 | - | CJJ 113 ≥0.95（剪），≥0.90（剥） |

**焊接方法：**
- **热楔焊（双轨搭接）：** 搭接 >100 mm，用于主焊缝
- **挤出焊（单轨搭接）：** 搭接 75 mm，用于细部修补

**测试方法：** CJ/T 234-2006 / GB/T 17643 / GRI GM19
**来源：** CJJ 113-2007 附录D / GRI GM19

---

### 5.3 界面剪切强度

```
τf = cₐ + σₙ · tan δ
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| τf | 界面抗剪强度 | kPa | HDPE/土工织物 5~15；HDPE/压实黏土 10~30 |
| cₐ | 界面黏聚力 | kPa | 0~10（多数 HDPE/土界面接近 0） |
| σₙ | 界面法向应力 | kPa | 上覆堆体压力产生 |
| δ | 界面摩擦角 | ° | HDPE/织物 8~18°；HDPE/黏土 15~25° |

**判定：** 界面强度 < 内部强度 → 沿界面滑移为控制工况；用 Janbu/Spencer 验算
**试验：** 大型直剪仪 ≥ 30 cm × 30 cm；三轴 ≥ 8 cm 直径
**来源：** CJJ 176-2012 §6.2 / ASTM D5321 / D6243

## 6. 复合衬垫等效渗透系数

**参考：** Rowe 1995 / Giroud 1997 / CJJ 176-2012 §6.6

### 6.1 调和平均（厚度加权）

```
k_eq = (H_f + H_m) / (H_f/k_f + H_m/k_m)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| k_eq | 复合衬垫等效渗透系数 | m/s | HDPE+GCL 系统 1e-12~1e-10 |
| H_m | 矿物料层厚度 | m | GCL 0.005~0.01；CCL 0.6~1.5 |
| H_f | 衰减层厚度 | m | - |
| k_m | 矿物料层渗透系数 | m/s | GCL 1e-12~5e-11；CCL 1e-9~1e-8 |
| k_f | 衰减层渗透系数 | m/s | - |

**假设：** 调和平均假定层流；各层水量相等；保守估计
**来源：** Rowe 1995 / Giroud 1997

---

### 6.2 Giroud 缺陷渗漏公式

```
Q = 0.976 · Cq · γw · Hw^0.9 · a^0.1 · ks^0.74   (m³/s)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| Q | 通过缺陷的渗漏流量 | m³/s | 单缺陷 1~1000 L/d |
| Cq | 接触质量系数 | - | 良好 0.21；不良 0.47；无 1.15 |
| γw | 水的重度 | N/m³ | 9810 |
| Hw | 渗滤液水头高度 | m | 0.3~1.0 |
| a | 缺陷面积 | m² | 1e-6 (1mm²) ~ 1e-4 (1cm²) |
| ks | 下卧层渗透系数 | m/s | GCL 1e-10；CCL 1e-9 |

**典型缺陷密度：** 1~10 个/公顷（EPA 参考）
**来源：** Giroud & Bonaparte 1989 / Giroud 1997

## 7. 污染物运移 对流-弥散

**参考：** Ogata & Banks 1961 / Bear 1979 / CJJ 176-2012 第9章

### 7.1 一维对流-弥散方程（Ogata-Banks 解）

```
C(x,t)/C₀ = (1/2)·[erfc((x − v·t)/(2·√(D·t))) + exp(v·x/D)·erfc((x + v·t)/(2·√(D·t)))]
```

**控制偏微分方程：**
```
R · ∂C/∂t = D · ∂²C/∂x² − v · ∂C/∂x − λ · C
```

其中 R = 1 + ρb·Kd/n

**边界条件：**
- C(0, t) = C₀ （源浓度恒定）
- C(∞, t) = 0 （半无限域）
- C(x, 0) = 0 （初始清洁）

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| C(x,t) | 位置x时间t的浓度 | mg/L | 0~C₀ |
| C₀ | 源浓度 | mg/L | 渗滤液 Cl⁻ 1500~5000；COD 5000~30000 |
| x | 迁移距离 | m | 0~50 |
| t | 迁移时间 | d | 30~3650 |
| v | 地下水流速 | m/d | 10⁻³~10⁻¹ |
| D | 水动力弥散系数 | m²/d | αL·v ; αL ≈ 1~100 m |
| erfc | 余补误差函数 | - | erfc(u) = 1−erf(u) |
| R | 阻滞因子 | - | 1+ρb·Kd/n |
| λ | 衰变速率常数 | 1/d | - |

**带阻滞修正：**
```
C(x,t)/C₀ = (1/2)·[erfc((x·R − v·t)/(2·√(D·R·t))) + exp(v·x/D)·erfc((x·R + v·t)/(2·√(D·R·t)))]
```

**带衰修正：** 整体乘以 exp(−λ·t)

**主对流主导简化（vx/D > 500）：**
```
C/C₀ ≈ 0.5·erfc((x − v·t/R)/(2·√(D·t/R)))
```

**来源：** Ogata & Banks 1961 (USGS) / Bear 1979 / CJJ 176-2012 §9

---

### 7.2 纵向弥散度参考值

| 尺度 (m) | 纵向弥散度 αL (m) | 介质 |
|---------|------------------|------|
| <1 | 0.001~0.01 | 实验室柱 |
| 1~10 | 0.1~1 | 野外小尺度 |
| 10~100 | 1~10 | 中尺度场地 |
| >100 | 10~100 | 区域含水层 |

**尺度效应：** 场地尺度越大弥散度越大（Gelhar 1992）
**来源：** Gelhar 1992 / Neuman 1990

## 8. 循环井影响半径

**参考：** Kusakin 经验式 / Zhang 2024 Hydrogeology Journal 32:817 / Liu 2024 环境科学研究

### 8.1 Kusakin 体积平衡法

```
R = √(Q · t / (π · H · nₑ))
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| R | 影响半径 | m | 5~50（GCW 修复井） |
| Q | 循环/抽注流量 | m³/d | 100~1000 |
| t | 运行时间 | d | 30~365 |
| H | 含水层饱和厚度 | m | 5~30 |
| nₑ | 有效孔隙度 | - | 砂层 0.15~0.25；粉砂 0.10~0.15 |
| π | 圆周率 | - | 3.14159 |

**假设：** 圆柱形影响区；体积平衡；不考虑边界补充

**其他常用公式对比：**

| 作者 | 公式 | 条件 |
|------|------|------|
| Weber | R = 2.45·H·√(k·t/nₑ) | 无压含水层 |
| Cooper-Jacob | R = 2.25·√(T·t/S) | 承压含水层 |
| Siechardt | R = 3000·s_w·√k | 经验式（m/d单位） |
| Kusakin | R = 575·s_w·√(H·k) | 经验式 |
| Lembke | R = H·√(k·t/N) | 考虑越流补给 |

**GCW 注：** 循环井(GCW)上下抽注同时进行，影响半径小于传统抽水井；垂向渗透率增大 → 影响半径减小（Zhang 2024）
**来源：** Kusakin / Zhang 2024 / Liu 2024

## 9. 库容估算

**参考：** CJJ 176-2012 §5.5 / 测量学标准

### 9.1 简化矩形法

```
V = A · H   (m³)
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| V | 库容体积 | m³ | 10⁵~10⁷ |
| A | 平均填埋面积 | m² | 10万~50万 |
| H | 平均填埋深度 | m | 20~60 |

**适用：** 概念设计/方案估算
**限制：** 忽略边坡几何，误差20~40%
**来源：** CJJ 176-2012 §5.5 简化法

---

### 9.2 台体/截锥体法

```
V = (H/3)·(A₁ + A₂ + √(A₁·A₂))   (m³)
```

**变量表**

| 符号 | 名称 | 单位 |
|------|------|------|
| A₁ | 顶面面积 | m² |
| A₂ | 底面面积 | m² |
| H | 高度 | m |

**适用：** 棱台形堆体（四边坡）；精度高于矩形法
**来源：** 测量学公式

---

### 9.3 梯形断面平均断面法

```
V = (L/2) · (A₁ + A₂)   (m³)
```

**多断面扩展：**
```
V = (D/2) · [A₁ + An + 2·ΣAᵢ内]
```

**变量表**

| 符号 | 名称 | 单位 |
|------|------|------|
| L/D | 两断面间距 | m |
| A₁/A₂ | 两端断面面积 | m² |

**来源：** 测量学

---

### 9.4 带边坡校正的横断面

**平坡情况：**
```
A = (b + n·h)·h   (m²)
```

**横坡情况：**
```
A = (s² − n²)/(n·b²) + 2·s²·b·h + n·s²·h²
```

**变量表**

| 符号 | 名称 | 单位 | 典型值 |
|------|------|------|--------|
| b | 底宽 | m | - |
| n | 边坡比 | - | 填埋场 1:2~1:3（n=2~3） |
| h | 堆高 | m | - |
| s | 横向坡度比 | - | - |

**来源：** 测量学横断面计算

---

### 9.5 考虑沉降的实际库容

```
V_实际 = V_几何 · (1 − ΔS / H₀)
```

**变量表**

| 符号 | 名称 | 单位 |
|------|------|------|
| V_几何 | 设计几何库容 | m³ |
| ΔS | 总沉降（双曲线法推算） | m |
| H₀ | 初始堆高 | m |

**典型值：** 垃圾堆体沉降占堆高 20~40%；通过分阶段堆填补偿
**分级堆填系数：** 1.2~1.4（实际填埋量 / 设计填埋量）
**来源：** CJJ 176-2012 §5.5
